# 📱 Cara Install PWA Timer PS di HP Android

## ✅ PWA sudah siap! Aplikasi ini sekarang bisa di-install langsung dari browser HP.

---

## 📲 Cara Install di Android (Chrome)

### Langkah 1: Buka di HP
1. Pastikan HP dan laptop terhubung ke WiFi yang sama
2. Buka Chrome di HP Android
3. Ketik IP laptop kamu, contoh: `http://192.168.1.100:3000`
   - Cek IP laptop: Windows → Run → cmd → ketik `ipconfig`
   - cari "IPv4 Address"

### Langkah 2: Install PWA
1. Tunggu website terbuka completely
2. **Chrome akan otomatis menampilkan popup "Install"** atau ikon ⤵️ di address bar
3. Klik "Install" atau ikon ⤓
4. Klik "Install app"

### Langkah 3: Selesai!
✅ Aplikasi "Timer PS" sudah terinstall di HP
✅ Bisa buat seperti aplikasi biasa (di home screen)
✅ Bisa jalan offline!
✅ Tampilan fullscreen seperti native app!

## 🔧 Troubleshooting

### Tidak muncul popup "Install"?
**Solusi:**
1. Pastikan sudah buka di Chrome (bukan browser lain)
2. Tunggu website loading completely
3. Cek menu Chrome (⋮) → "Add to Home Screen" atau "Install App"
4. Refresh halaman dan coba lagi

### Aplikasi tidak bisa jalan offline?
**Solusi:**
1. Buka aplikasi sekali dengan internet
2. Tunggu semua aset ter-download
3. Baru bisa dipakai offline

### Icon tidak muncul?
**Solusi:**
1. Clear cache Chrome
2. Uninstall aplikasi
3. Install ulang
